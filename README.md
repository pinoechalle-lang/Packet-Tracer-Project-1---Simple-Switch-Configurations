# Packet-Tracer-Project-1---Simple-Switch-Configurations
## Simple LAN network set-up employing switch-to-switch topology and with simple configurations

### In this project activity, the network admin must configure the LAN with the following requirements:

> Switch-A and Switch-B must have a password configured respectively for CLI access, EXEC mode, and remote access. Additionally, the password must be "cisco".

> Switch-A and Switch-B must have the configured passwords encrypted in the configuration file.

> All switches and PCs must follow the subnet range 192.168.1.0 /24. However, Switch-A must have the IP address, 192.168.1.2, and Switch-B with the IP address, 192.168.1.3, configured to their default VLAN, which is VLAN 1. The remote access must use the Telnet protocol.

> All PCs must follow the given subnet range. Any address is acceptable aside from *.2* and *.3*.
